# FPGA Clock Domains

> **Related notes:** [[04_Firmware_FPGA]]

## 1. Primary Clock Domains

The AERIS-10 FPGA design uses a multi-clock architecture to bridge high-speed RF converters with lower-speed DSP and USB interfaces.

| Clock Domain | Source | Frequency | Used By | Crossing Mechanism | Evidence | Confidence |
| ------------ | ------ | --------: | ------- | ------------------ | -------- | ---------- |
| **System/DSP (`clk_100m`)** | AD9523 | 100 MHz | DSP Pipeline, MCU Interface, Mode Controller | Async FIFOs (USB), CDC sync chains (MCU) | `radar_system_top.v` | Confirmed |
| **DAC (`clk_120m_dac`)** | AD9523 | 120 MHz | DAC output interface | FIFO / Dual-clock RAM from DSP | `radar_system_top.v` | High |
| **ADC LVDS (`adc_dco_p`)** | AD9484 | 400 MHz | ADC input interface (DDC) | N/A (Decimated internally) | `radar_receiver_final.v` | Confirmed |
| **USB 2.0 (`ft601_clk_in`)** | FT2232H | 60 MHz | FT2232H FIFO logic | Async FIFO | `radar_system_top_50t.v` | Confirmed |
| **USB 3.0 (`ft601_clk_in`)** | FT601 | 100 MHz | FT601 FIFO logic | Async FIFO | `radar_system_top.v` | Confirmed |

---

## 2. Clocking Architecture & CDC

### ADC Clocking
The AD9484 provides a 400 MHz differential clock (`adc_dco_p/n`) alongside the LVDS data. The FPGA captures data using this clock via an IBUFDS. The raw 400MSPS data is immediately decimated down to the 100 MHz system clock domain inside the `ddc_400m` module.

### DAC Clocking
The DAC operates at 120 MHz. The DSP pipeline operates at 100 MHz. The IF chirp data generated by the `radar_transmitter` is crossed into the 120 MHz domain before output.

### USB CDC
Data from the DSP pipeline (100 MHz) is pushed into an asynchronous FIFO in `usb_data_interface.v`. The read side of the FIFO is clocked by the USB controller's clock (60 MHz for FT2232H, 100 MHz for FT601).

### MCU CDC
The MCU uses asynchronous GPIO toggles (e.g., `stm32_new_chirp`). The FPGA uses multi-stage flip-flop synchronizers (in `cdc_modules.v`) to safely bring these signals into the `clk_100m` domain before triggering the chirp state machine.

---

## 3. Replication Impact

The FPGA completely relies on the external AD9523 Frequency Synthesizer to provide the 100 MHz and 120 MHz clocks. The FPGA does not appear to use an internal PLL/MMCM to generate the system clock from a raw crystal, meaning the MCU *must* successfully configure the AD9523 over SPI before the FPGA can boot its DSP pipeline.
